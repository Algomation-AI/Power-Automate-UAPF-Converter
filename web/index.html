pa2uapf
Source on GitHub UAPF specification

Turn Power Automate flows into open BPMN processes.

Drop a solution export or a single flow definition. You get a UAPF package: the process as a BPMN diagram, every expression and connector setting kept, and a report of what converted exactly and what needs a person.

No export at hand? Convert a sample:

Files are converted in memory and discarded. Nothing is stored, logged or shared; the result is downloaded straight to your browser.

      What the converter does
      
    
      
      
      
        
      Structure becomes BPMN
      
        
      Triggers, conditions, switches, loops, parallel branches and try/catch scopes become start events, gateways and sequence flows that any BPMN tool can open.
      
      
      
      
      
        
      Logic stays in the package
      
        
      Every expression and connector parameter is copied verbatim into the step's settings. Nothing about the flow is left for the runtime to know.
      
      
      
      
      
        
      Connectors become capabilities
      
        
      SharePoint, Outlook, Teams, HTTP and the rest map to generic capabilities such as sharepoint.get-items@1, so any UAPF-IP agent that offers them can run the process.
      
      
      
      
      
        
      Nothing is hidden
      
        
      Each action is reported as exact, approximated or manual, with the reason. Approvals that wait for days and AI Builder prompts are flagged, not guessed.
      
      
      
    
      
    
      Open source under Apache-2.0. Run it on your own servers with docker run or as a command-line tool: pa2uapf MySolution.zip.
